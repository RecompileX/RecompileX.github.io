# Hamza Kamal / RecompileX

Building systems from the ground up.

A responsive static portfolio featuring my public C++ games and tools. Open `index.html` locally to preview; no package install or build step is required. GitHub Pages serves the root of `main`.

## Editing

- `index.html`: biography, project descriptions, and links.
- `styles.css`: responsive navy and blue theme.
- `assets/`: actual gameplay screenshots for Wildfire Simulator, Breakout++, and Pong++.
- `favicon.svg`: site icon.

Wildfire screenshots come from the game's existing assets. Breakout++ and Pong++ screenshots were captured directly from running builds of their existing C++ source, without modifying the games. All screenshots are stored locally with the site. The Toolbox card displays a code sample, since it is a utility library. Google Fonts supplies the fonts, with local fallback fonts if unavailable.

## Domain setup

The planned custom domain is `recompilex.is-a.dev`. The registration configuration is prepared separately in `RecompileX/register`; no registration pull request has been submitted. Keep this site at its default GitHub Pages address until the domain is approved. After approval, configure `recompilex.is-a.dev` in Settings → Pages → Custom domain and enable HTTPS when available.
